# Directo a Obra

## Acerca de

Plataforma de comercio electronico para venta de materiales de construccion, desarrollada en PHP con base de datos MySQL. Permite a los clientes navegar por un catalogo de productos, filtrar por categoria y rango de precio, agregar articulos a un carrito de compras y realizar pedidos con generacion automatica de facturas enviadas por correo electronico. Aplicacion web monolítica ejecutada en un servidor local con Apache y PHP, sin componentes de procesamiento en tiempo real ni arquitectura distribuida.

## Caracteristicas principales

- Catalogo de productos de construccion con filtrado por categoria y rango de precio.
- Carrito de compras gestionado mediante sesiones de PHP.
- Generacion y envio de facturas en HTML por correo electronico mediante PHPMailer y SMTP de Gmail.
- Base de datos MySQL para productos, categorias y transacciones.
- Frontend con HTML5, CSS3, JavaScript, Bootstrap 5 y Tailwind CSS mediante CDN.

## Stack tecnologico

| Categoria | Tecnologia |
|-----------|------------|
| Backend | PHP 8.x |
| Base de datos | MySQL |
| Frontend | HTML5, CSS3, JavaScript, Bootstrap 5 (CDN), Tailwind CSS (CDN) |
| Correo electronico | PHPMailer con SMTP de Gmail |
| Servidor web | Apache (XAMPP) |
